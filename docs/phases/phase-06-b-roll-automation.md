# Phase 6: B-Roll Automation

Phase 6 implements an intelligent stock video overlay system that fetches free stock footage based on conversational context and automatically splices it into the final rendered video.

## 6.1 Keyword Extraction

Rather than spinning up an independent LLM call, this stage leverages the robust contextual understanding from **Phase 3 (AI Video Understanding)**. The Groq AI edit plan already generates B-roll placement suggestions, including exact `startSec`, `endSec`, and highly specific `suggestedQuery` fields. 

The `broll-keyword-service` extracts these structured requirements to ensure that B-roll is placed precisely where conversational context dictates, remaining on screen exactly as long as the topic is discussed.

## 6.2 Free B-Roll Search

The `broll-search-service` simultaneously queries the **Pexels Video API** and the **Pixabay Video API** for each keyword. 
- Using `Promise.allSettled`, it ranks and returns the first valid HD `.mp4` link from either service, providing excellent fault tolerance and maximizing coverage.
- Videos are downloaded and cached per-asset in the `storage/assets/{id}/broll/` directory so they are only fetched once, even if the user re-renders the project multiple times.

## 6.3 Smart B-Roll Placement (FFmpeg)

The `broll-engine` constructs complex FFmpeg filter graphs to seamlessly overlay the downloaded stock footage onto the main video.
- **Dynamic Resizing**: Uses the `scale` and `crop` FFmpeg filters to dynamically adjust the stock footage aspect ratio to perfectly fill the original video's bounds, regardless of whether it's horizontal (16:9) or vertical (9:16).
- **Precision Timing**: Shifts the presentation timestamps (`PTS`) of the stock footage to exactly align with the `startSec` generated by the AI.
- **Overlay**: Employs the `overlay=enable='between(t,start,end)'` filter to precisely flash the B-roll on screen without disrupting the underlying video or audio tracks.

## Preset Integration

B-roll automation is integrated into the frontend `EditorPanel` and is enabled by default for presets that benefit from visual variety, such as **Cinematic**, **Documentary**, and **Breaking News**. Users can manually toggle this feature.
